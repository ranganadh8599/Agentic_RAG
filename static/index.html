❓ How to use
  1. Choose where to search — pick a table in Search in table, or leave it on All collections.
  2. Upload documents — drag files into Drop documents or click browse files. Type a name in Upload to table to create a new table automatically.
  3. Ask questions — type below and press Enter. Click any [n] citation in the answer to jump to its source.
  4. Documents & Stats — show the files and chunk counts for the selected table only.
History ⓘ Your saved conversations. Click one to resume it — each chat is stored under your account, so other users can't see it.

Drop documents ⓘ Drag & drop files here or click browse files to ingest them. Supported: PDF, images (PNG/JPG/JPEG/GIF/WEBP/BMP), text / Markdown / CSV / JSON, Word (.docx), Excel (.xlsx), PowerPoint (.pptx). The text is extracted, chunked, embedded and stored in PostgreSQL automatically.
